# TP Django — Parc d'engins (SI de chantier en 4h)

## Objectif
Avoir un mini-SI fonctionnel  via Django Admin :
- Engins
- Interventions
- Pièces détachées
- Association avec quantité (InterventionPiece)

## Démarrage rapide (Windows PowerShell)
1) Ouvrir PowerShell dans ce dossier
2) Exécuter :
   .\run_windows.ps1

## Démarrage rapide (Linux/macOS)
1) Ouvrir un terminal dans ce dossier
2) Exécuter :
   bash run_linux.sh

## URL
Admin : http://127.0.0.1:8000/admin/
